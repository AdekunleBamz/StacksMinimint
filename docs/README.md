## Validation Shortcut

From the project root, run `npm run check:fast` to execute a lightweight pre-push verification flow.

## Contributing

When adding new documentation, please follow these guidelines:

1. Use clear, concise language
2. Include code examples where applicable
3. Keep documentation close to the code it describes
4. Update the table of contents when adding new files
