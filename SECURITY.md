# Security Policy

## Supported Versions

We currently provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes            |
| < 1.0   | ❌ No             |

## Reporting a Vulnerability

We take the security of StacksMinimint seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

**Please do not report security vulnerabilities via public GitHub issues.**

Instead, please send an email to [bams.kunle@gmail.com](mailto:bams.kunle@gmail.com).

Please include the following information in your report:
- Type of issue (e.g., buffer overflow, SQL injection, RCE)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected code
- A dynamic-analysis report or a functional exploit (Proof of Concept)
- Steps to reproduce the issue

We will acknowledge receipt of your vulnerability report within 48 hours and send a more detailed response within 7 days.

## Disclosure Policy

We follow a coordinated disclosure model. We ask that you do not share your findings publicly until we have had a chance to investigate and address the issue. We will work with you to ensure that your report is addressed in a timely manner and that you are credited for your discovery.
